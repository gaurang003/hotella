Hotella - (Hotel Management System)

Technology Stack: Java, Spring Boot, Hibernate/JPA, MySQL, REST APIs

Project Description

Developed a Hotel Management System to streamline hotel operations such as room booking, customer management, reservations, check-in/check-out, and payment tracking.

Key Features
Room booking and reservation management
Customer registration and profile management
Check-in and check-out operations
Room availability tracking
Payment and billing management
Admin dashboard for hotel management
RESTful APIs for hotel operations
Responsibilities
Developed backend APIs using Spring Boot.
Designed database schema and relationships using MySQL.
Implemented CRUD operations using Spring Data JPA and Hibernate.
Added validation and exception handling.
Tested APIs using Postman.
